PERSONAL PROFILE WEBSITE — Nuhamin Feleke

Contents
- index.html: Home page
- about.html: Biography and interests
- skills.html: Education, skills, progress, definitions, and learning plan
- projects.html: Project portfolio and achievements
- media.html: Audio, video, YouTube iframe, and interests
- contact.html: HTML form with labels and browser validation
- images/: SVG illustrations used by the pages
- media/: Add your own audio/video files here
- documents/: Reserved for optional downloadable project reports

How to open
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Use the navigation menu to visit all six pages.

Important notes
- This assignment uses HTML only; there is no CSS or JavaScript.
- The profile picture is an illustrated avatar, not a photograph of the student. Replace images/profile-avatar.svg with a suitable image if your instructor requires a real profile image (update the file reference if the format changes).
- The media page expects media/favourite-music.mp3 and media/favourite-video.mp4. Add files you own or have permission to use; the rest of the website works without them.
- The contact form demonstrates HTML validation but does not send messages because no backend/form service is connected.
- The progress percentages are clearly labelled as estimates and can be adjusted.
- Check the institution dates and project descriptions before submission to ensure they match your own records and your instructor's expectations.
